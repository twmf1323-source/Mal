# Mal · 韓語文法筆記本

韓語文法規則筆記本：查詢以 **API 文法盤點** 為主；**尚未收錄**的名稱可加入待辦。  
規則標題格式：**中文（韓語）**（例如 `해요體（-아/어요）`）。  
**不做**動詞變化格子；不規則各自獨立成卡。  
本地掃描與選字建議可搭配 **Kiwi 形態素分析**（免費開源）：冠形詞尾 `-ㄴ` 這類只活在받침裡的語尾，不再只靠字串搜尋。

## 功能

| 功能 | 說明 |
|------|------|
| API 查詢 | 已收錄：句中多彩標記＋規則卡；未收錄：下方列表 |
| 查詢歷史 | 最近查過的句子（本機）；可「再看一次」／刪除／清空 |
| 規則 CRUD | 新增／編輯／刪除；標題中文（韓語） |
| 已收錄比對 | 盤點結果與筆記本規則標題嚴格比對 |
| 缺失→待辦 | 單筆或全部加入待辦，之後建立規則 |
| AI 自動填寫 | 設定 API Key 後依規則名補齊說明 |
| 匯入／匯出 | JSON 備份（設定頁） |
| 形態素分析 | 背景預設開啟；設定頁可關。選字套用會依 Kiwi 語素置頂建議（如選 `예쁜` → 冠形詞形（-ㄴ/은）） |
| 種子資料 | 內建常見語尾、助詞、不規則等 |

## 快速開始

### 本機靜態伺服器（建議）

雙擊 `index.html` 會被瀏覽器擋住讀取本機 WASM／種子檔。有網路時會改從 GitHub Pages 載入；離線請雙擊 **開啟筆記本.bat**，或：

```bash
cd "韓語文法筆記本"
npx --yes serve .
# 或
python -m http.server 8080
```

瀏覽器開啟顯示的網址。

### 部署到 Netlify

1. 將此資料夾連到 Netlify（或拖曳部署）
2. Publish directory 設為專案根目錄（已提供 `netlify.toml`）
3. 無需 build

## 規則卡片欄位

```text
id, title, category, explanation, structure,
created_at, updated_at
```

- **title**：`中文功能名（韓語標記）`
- **category**：語尾／助詞／不規則／時態／敬語／連接／句型／其他
- **structure**：可視化結構式，如 `詞幹＋지 않다`、`나＋는→난`、開／閉用 `／` 分列
- **explanation**：概念說明；**盡量不附例句**
- 無 `keywords`（本地掃描已取消）、無變化格子

## 查詢流程

### 查詢（僅 API）

1. 輸入單詞或整句（需已設定 API Key）  
2. 呼叫 API 盤點文法點（名稱格式：中文（韓語））  
3. 與筆記本比對 → **已收錄**／**尚未收錄**（未建立深紅色）  
4. 缺失可「加入待辦」或「建立規則」  

## 資料存放

- 瀏覽器 **localStorage**（鍵名 `kgn_*`，與日語 `jgn_*` 分開）
- 首次載入讀取 `data/seed-rules.json`
- 設定頁可匯出／匯入 JSON；「重設種子」會載入最新種子

## 設計原則

1. 查詢以 **API 盤點** 為準；筆記本用嚴格比對標「已收錄」
2. 不規則另立規則，不做類型格子
3. 規則名統一 **中文（韓語）**
4. **一次一個主題**：API 只報句中實際表面形；開／閉音節同文法可同卡，結構式「開…／閉…」
5. 本地關鍵字掃描仍保守；語尾／助詞消歧交給 Kiwi（設定頁可關）

## 形態素分析（Kiwi）

- 授權：LGPL-2.1-or-later，本機執行、不需付費或 API Key
- 模型與 WASM 在 `vendor/kiwi/`、`vendor/kiwi-nlp/`（首次載入約十幾秒）
- 角色：定位與消歧（`는`＝冠形 ETM 或主題 JX；`-ㄴ` 標在宿主音節），不取代 API 助教命名
